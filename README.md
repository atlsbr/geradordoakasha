## 🎯 Sobre o Projeto

O **Akasha Hub Content Generator** é uma ferramenta completa que usa inteligência artificial (Google Gemini) para criar conteúdo de alto impacto para redes sociais e blog.

Desenvolvido especificamente para **akashahub.com.br** ([@akasha.hub](https://instagram.com/akasha.hub)), focado em transformação de consciência, prosperidade e poder pessoal.

---

## ✨ Funcionalidades

- 📱 **Posts para Instagram** - Conteúdo magnético e engajador
- 🎬 **Roteiros de Reels** - Scripts prontos para executar
- 🎵 **Conteúdo TikTok** - Viral e impactante
- 🐦 **Tweets/Threads** - Provocadores e instigantes
- 📝 **Artigos de Blog** - Longform transformador

## 🚀 Como Usar

### 1️⃣ **Acesse o App**
👉 [**CLIQUE AQUI PARA USAR**](https://SEU-USUARIO.github.io/NOME-DO-REPO/akasha-gerador-conteudo.html)

### 2️⃣ **Obtenha sua API Key (Gratuita)**
- Acesse: [Google AI Studio](https://makersuite.google.com/app/apikey)
- Crie uma conta Google (se não tiver)
- Clique em "Create API Key"
- Copie sua chave

### 3️⃣ **Preencha os Campos**
- Cole sua API Key
- Defina o tema do conteúdo
- Escolha o tipo (Instagram, Reels, TikTok, etc.)
- Selecione o tom de voz
- Descreva seu público-alvo

### 4️⃣ **Gere e Copie**
- Clique em "Gerar Conteúdo Magnético"
- Aguarde alguns segundos
- Copie o conteúdo gerado
- Use onde quiser!

## 🛠️ Instalação Local

Se quiser rodar localmente:

```bash

# Entre na pasta

# Abra o arquivo no navegador
open akasha-gerador-conteudo.html
```

Ou simplesmente baixe o arquivo `akasha-gerador-conteudo.html` e abra no seu navegador!
